# Fonts

Rajdhani (Indian Type Foundry) and Inter (The Inter Project Authors) are licensed under the SIL Open Font License, Version 1.1. The licence texts are in this folder.

These files are Latin subsets, for the style guide to open from `file://`. A live site may load the full families from Google Fonts, or self-host the official releases.

- `Rajdhani-Medium.woff2`, `Rajdhani-SemiBold.woff2`, `Rajdhani-Bold.woff2`
- `Inter-roman.woff2`, `Inter-italic.woff2` (variable, weight 100–900, optical size pinned to 18)
